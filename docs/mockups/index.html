データモデルヒント — 画面 UI から導出した JSON 構造の候補

本プロジェクトはデータベースを使わず、GCS 上の JSON でコンテンツを管理する。以下は確定した設計ではなく、レビューの入力。

構造候補主要フィールド導出元（画面ID）
aiusage（ルート） principle（原則の 1 文・必須）／sections[] visitor-aiusage
aiusage.sections[] title（必須）／summary（必須）／items[] visitor-aiusage
aiusage.sections[].items[] title（必須）／description（必須）／decision（任意）／url（任意） visitor-aiusage

セクションは 土台をつくる / 開発工程で使い分ける / 情報収集を自動化する / AI に任せないこと の 4 つ。 文言はデータ側（aiusage.json）に持ち、この仕様書は構造だけを定める。 非公開リポジトリの題材には url を付けない（訪問者に 404 を見せないため）。詳細は screens.md を参照。
